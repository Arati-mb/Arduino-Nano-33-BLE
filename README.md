# Arduino Nano 33 BLE Sense Lite Documentation

##  Objective
The objective of this project is to study and understand the working of the
Arduino Nano 33 BLE Sense
development board, including its microcontroller, built-in sensors, Bluetooth Low Energy (BLE) communication, and camera interfacing. The project aims to acquire sensor data, capture images using the OV7675 camera module, and explore the implementation of TinyML and computer vision applications on a low-power edge device.
